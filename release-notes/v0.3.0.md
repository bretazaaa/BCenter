## What's new

- **Connections** — one place for every machine you reach over SSH (VMs, LXC, NAS, servers): folders, colored tags with filters, search, and a "To configure" view listing Proxmox guests and NAS without SSH access yet.
- **Import from other tools** — XPipe, OpenSSH (`~/.ssh/config`), PuTTY, WinSCP and MobaXterm. Names and folders can be edited before importing; passwords can be typed once for several machines; host keys are checked against `~/.ssh/known_hosts` and every connection is tested before it is added.
- **Tabbed terminal** — all shells open in a panel at the bottom of the window, with tabs, resize and maximize.
- **File manager (SFTP)** — browse, upload (button or drag and drop from Explorer), download, create, rename, delete, and edit text files in place.
- **Detach and reattach** — any terminal or file tab can be moved to its own window and brought back; SSH sessions keep running without reconnecting.

## Security

- Every window now runs in Chromium's sandbox; navigation, pop-ups and webviews are blocked, and device permissions (camera, microphone…) are always denied.
- Stricter Content Security Policy in release builds.
- Downloads from a server can no longer write outside the chosen folder, even with crafted file names.
- `ws` dependency upgraded (security advisory); `reg.exe` is called by absolute path.
- Passwords are never read from other tools' vaults: they stay encrypted there.

## Improvements

- Faster startup: charts and the terminal are loaded on demand.
- Shell buttons removed from other pages: everything is in Connections.
- `npm run dev` restarts the engine automatically when its code changes (development).
