## What's new

- **NAS on the dashboard** — storage, disks, apps and health of every NAS at a glance, and NAS task runs in the recent activity feed.
- **NAS monitoring** — CPU, memory, used storage and temperatures (system and hottest disk) in the Monitoring page, sampled by BCenter at each refresh (up to 24 hours).
- **Add menu** — the toolbar's *Add* button now offers a Proxmox server, a NAS or an SSH machine.
- **Smoother app updates** — BCenter checks for updates at startup and offers to install them as soon as they are downloaded. Updates now install silently and BCenter restarts by itself (no installer wizard, starting with the next update).

## Fixes

- `npm run dev` can run next to the installed app without losing access to saved credentials (development only).

## Reminder — 0.2.0

- New **NAS** page: TrueNAS (SCALE / CORE), Synology DSM, Unraid, OpenMediaVault, QNAP (basic) and Proxmox Backup Server.
- Pools and volumes, disk health and temperature, shares, services, apps and containers, data tasks and alerts — with direct actions (services and apps, snapshot / replication / sync / backup tasks, scrub, updates, reboot).
- NAS alerts in the alert center with Windows notifications; SSH shell on the NAS.

> Updating from 0.2.0: the installer wizard is shown one last time. Later updates install silently.
