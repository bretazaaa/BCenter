## What's new

- **Automatic updates at startup** — when a new version is available, BCenter downloads it while the splash screen is shown, installs it silently (no installer window) and restarts by itself. It can be turned off in Settings › BCenter updates; the update is then offered instead.

## Fixes

- Settings: the "Unsaved changes" bar now stays at the bottom of the window.

See [0.3.0](https://github.com/bretazaaa/BCenter/releases/tag/v0.3.0) for Connections, the file manager, imports and the security hardening.
